# Reporting a security problem

Please do not open a public issue for a security problem.

- Use GitHub's private vulnerability reporting on this repository ("Security" tab → "Report a vulnerability"), or
- email the maintainer at the address shown in the app under Settings → Updates → About.

Include the app version (Settings → Updates), your operating system, and steps to reproduce. You will get a reply within a few days. Fixes ship through the app's built-in updater; every update package is signed and the app refuses unsigned or altered packages.
